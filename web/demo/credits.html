A captured room, made playable.

This demo uses a public Eyeful Tower room capture. The source sequence comes from a photographic capture rig. It is not a smartphone recording or the author's room. This room's exact source and hashes.

The dataset was relicensed under MIT in March 2026. Full dataset license · Source and provenance.

Camera poses, Gaussian reconstruction and object masks were produced with VGGT, gsplat and SAM 3 on a Colab L4. The browser uses three.js, Spark and Rapier. Captured objects have movable rigid bodies. Collisions, scale and hidden surfaces are approximate; these compact demos omit higher-order spherical harmonics to reduce download size. Each room displays its actual object and collider counts.

The default VGGT weights have non-commercial terms. SAM 3 requires approved model access and its own terms. Dataset licensing does not override model restrictions.
